              ⚠️ Friends needs a one-time setup

              This is the one part of Zenora that needs a real backend, since friends have to reach each other across separate devices. 1) Go to console.firebase.google.com and create a free project. 2) In the project: Build → Firestore Database → Create Database → start in test mode. 3) Project Settings (gear icon) → General → "Your apps" → click the web icon (</>) → register an app → copy the firebaseConfig object shown. 4) Open this file's HTML, find const firebaseConfig = { ... } near the top of the script, and paste your real values in over the placeholders. 5) Save and re-upload to your site. This card will disappear once it's working.
